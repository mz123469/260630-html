# 期末提案｜9 頁草稿範本

**每頁回答一個問題就好**。把括號內換成自己的情境；案例、分數與完成進度要用**實際結果**。

## 1｜你要做什麼？

**（系統名稱）**：一句話說明「幫誰、解決什麼問題」。

## 2｜現場有什麼問題？

寫出現在的做法、最主要的痛點，再舉一個具體情境。

## 3｜系統怎麼分工？

沿用課堂比喻「**兩張臉／大腦／器官**」，畫三個框：

| 區塊 | 要畫的內容 | 技術 |
|---|---|---|
| **前端：兩張臉** | 病人頁、醫護頁 | Vue.js |
| **後端：大腦** | API、AI 分流、CDS 判斷 | Express |
| **外部服務：器官** | AI 理解文字、FHIR 存取病歷 | Gemini、FHIR Server |

## 4｜資料怎麼一寫一讀？

畫兩條箭頭，交會於**同一筆 Observation**：

- **寫**：病人 → API → Gemini → FHIR Observation
- **讀**：醫師 → CDS Hooks → FHIR 查詢 → 警示卡

標出 **Patient ID、`code`、`valueQuantity`、`component`**。課堂沿用 `80615-8`，其語意問題見[附錄](../附錄.md)。

## 5｜AI 怎麼判斷？

寫出 Prompt 的**角色、輸出欄位、你加的一條判斷規則**。點名 `urgency_score`、`needs_human_intervention`、`summary`。

## 7｜加分做哪一項？（二選一）

- **CDS Hooks：**hook、service id、什麼情況彈卡。
- **SMART on FHIR：**如何 launch、scope、token 拿來讀什麼。

## 8｜怎麼避免出錯？

寫**隱私、AI 幻覺、偏見**各一個具體做法。一定要說清楚：**AI 失敗不能算成低風險**。
