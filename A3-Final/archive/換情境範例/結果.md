# 換情境示範｜用藥副作用分流

這是 **Demo 的參考案例**，作業要換成自己的情境。完整 AI 回傳保存在 [`執行輸出.txt`](執行輸出.txt)；再次執行的分數可能不同。

## Prompt 改哪裡？

| 原本 | 這份示範 |
|---|---|
| 個案管理師做情緒分析 | 臨床藥師做用藥副作用分流 |
| `symptoms` | `side_effects`，並加 `medication` |
| 沒有情境規則 | 加「病人說沒事，也要看症狀本身」 |

**共用欄位不要改名：**`urgency_score`（1–10 整數）、`needs_human_intervention`（布林值）、`summary`（字串）。改 Prompt 時也要改 `responseSchema`；整合回後端時，把 `side_effects` 對應回 `symptoms`。

## 實測 3 個案例

| 類型 | 病人主訴 | AI 結果 | CDS 卡片 |
|---|---|---|---|
| 想自行停藥 | 「降血壓的藥吃了兩個禮拜，一直乾咳，晚上咳到睡不著，我想先自己停藥看看會不會好。」 | **6 分**、需人工；摘要：乾咳影響睡眠，想自行停藥 | warning |
| 輕微不適但有問題 | 「新開的止痛藥吃了胃有一點不舒服，還可以忍，想問是不是要飯後吃比較好？」 | **3 分**、需人工；摘要：胃部不適，詢問服藥方式 | warning（人工介入） |
| 反話／壓抑 | 「沒事啦，藥我都有照吃，就是這幾天爬樓梯常常喘不過氣，大概是天氣太熱，不用麻煩醫生。」 | **8 分**、需人工；摘要：淡化喘不過氣的症狀 | critical |

**觀察：**第二例只有 3 分，卻仍需要有人回覆；第三例說「沒事」，實際主訴仍有風險。**不要只看分數，更不能把 AI 失敗當成 0 分。**

### 案例 JSON 在哪？

以上三例的**原始 JSON** 全部保留在 [`執行輸出.txt`](執行輸出.txt)。交作業時，請把**自己執行的三份 JSON** 放入 `案例.md`，不要拿本檔分數當成你的結果。

## 自己測

進入 `Demo/換情境範例/` 後，安裝 `@google/generative-ai`、`dotenv`，設定 `.env` 的 `GEMINI_API_KEY`，執行 `node cases.js`。

完成後，把 Prompt 與 Schema 貼回 `AI-Patient-Triage-System/services/aiService.js`，再跑一次 [一寫一讀](../../package/README.md#4-一寫一讀照順序驗證)。
