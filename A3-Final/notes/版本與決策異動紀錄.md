## 3. 已知未做（接手優先序）

1. 聯測主機的實際 URL、Keycloak client_id、Gazelle Test ID：官網沒公布，報名後才拿得到 → 填進 `.env` 即可。
2. ~~Track 1 轉換器~~ v14 已做（D29）。還沒做：拿到聯測主機與 answer-keys 後，用官方 `fhirfox-validator validate <bundle> <情境ID>` 逐案比對；AllergyIntolerance、ImagingStudy 有規則但範例沒放。
3. Observation 的 UCUM `{score}` 仍有 1 個 Warning；改成 `1` 可清掉，但語意變差，未改。
4. 共用伺服器上「更新機構」會覆蓋別人的 `org-hosp-example`；聯測時改用自己的機構代碼。
5. Gemini SDK `@google/generative-ai` 0.24 官方已停止更新（D25）；換 `@google/genai` 時要改 `services/aiService.js` 的呼叫方式，不是只改套件名。
6. 一般使用的醫師端登入沒有密碼（證書字號＋姓名，示範用）；上線前要接 SMART on FHIR／OAuth 使用者登入（D27）。
7. twcore.hapi.fhir.tw 跑 0.3.x：PractitionerRole.specialty 用官方 Spec-0001（SNOMED）會整包 422；範例先不帶 specialtyCode（spec 已知事項 5）。
8. 匯入的就醫、診斷、檢驗等重複上傳會新增第二份（D32）；validator_cli 需要 Java 17 與 tools/validator_cli.jar，測試包使用者沒有 Java 就只能轉換預覽、不能上傳。
