# 聯測總覽

TW CONNECTATHON
## 台灣聯測松
台灣核心實作指引、癌症用藥事前審查、網路使用者授權與國際病人摘要。

國家

#1台灣核心實作指引
TW Core IG為定義適用於臺灣健康照護資料交換需求的Resources以及必要的在地化，作為國家標準基線最小限制集。本賽道分類主要協助驗證健康照護資訊系統開發與實作者對於TW Core IG的基本實作能力，加強使用TW Core IG開發實務專案之實作能力。→

政府

#2癌症用藥事前審查
驗證根據政府專案計畫提供的FHIR IG，提供使用情境用來驗證參加者是否具備特定的政府FHIR專案之實作能力。→

應用

#3網路使用者授權
提供各種實際健康照護機構資料交換的應用情境，包含學術研究、商業情境、個人健康管理、院際交換等，用來驗證參加者是否具備各種交換的應用情境之實作能力。→

國際

#4國際病人摘要
本分類依據現有的國際電子健康紀錄交換規範，提供跨國的交換應用情境，用來驗證參加者是否具備跨國交換之實作能力。 
 專案：採用國際常用的專案聯測松 (Projectathon)運作模式，透過聯測來驗證專案設計的FHIR IG之適用性以及可行性。透過短時間的測試與驗證，以確保彼此的系統之間可以有效地依據國際之間的跨院交換規格來達到資料交換。根據開發中的FHIR IG進行測試，並修正其系統以達到標準要求。→
